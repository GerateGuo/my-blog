## 每篇写什么

一份实验记录按这个顺序展开，缺哪块就空着，但别只贴代码：

- **问题描述** —— 这个实验要解决什么问题，输入输出是什么，有没有特殊约束
- **思路与分析** —— 为什么选这个做法，复杂度怎么推，和其他思路比差在哪
- **代码实现** —— 核心部分贴进正文，完整代码放在 GitHub 仓库，正文里给链接
- **实验结果** —— 运行输出、耗时对比、递归树或状态转移过程截图，能截图就别只用文字
- **踩坑与反思** —— 哪里想错了，怎么定位的，最后怎么改的

## 一些约定

- 每篇都打上「算法设计与分析」分类，从「归档」和「标签」也能找到
- 截图统一放在 `source/images/algorithm-design/<实验编号>/` 下，正文里用 `/my-blog/images/algorithm-design/...` 引用（本站根路径是 `/my-blog/`，少写这一段线上会 404）
- 代码块标注语言（`c`、`cpp`、`python`），高亮才准
- 新建文章用模板：`npx hexo new algorithm "实验一 xxx"`，分类和段落骨架会直接生成好
